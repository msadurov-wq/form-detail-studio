# FORM / Detail Studio — Telegram-заявки (заготовка для Netlify)

Сайт и серверная функция для отправки формы в Telegram. Секретный токен бота не хранится в HTML: он задаётся в Netlify Environment Variables.

## Что уже подготовлено
- `index.html` — сайт с формой, которая отправляет данные в серверную функцию.
- `netlify/functions/send-telegram.mjs` — проверяет обязательные поля и отправляет сообщение в Telegram Bot API.
- `netlify.toml` — настройки публикации и функций Netlify.

## Перед запуском
1. Войдите в Netlify и создайте новый сайт, загрузив папку проекта/репозиторий, содержащий `index.html`, `netlify.toml` и папку `netlify`.
2. В настройках сайта откройте **Environment variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен, который выдал BotFather (секретный; не вставлять в HTML и не отправлять в чаты).
   - `TELEGRAM_CHAT_ID` — ID получателя Telegram.
3. Запустите новое развёртывание после сохранения переменных окружения.
4. Убедитесь, что владелец сначала открыл личный чат с ботом и нажал `/start`.
5. Откройте опубликованный сайт и отправьте тестовую заявку. Проверьте, что сообщение пришло в нужный чат.

## Важно
- Не публикуйте токен в GitHub, HTML, скриншотах или публичных сообщениях. Если он раскрыт, отзовите его в BotFather и создайте новый.
- Локальное открытие `index.html` двойным нажатием не подключает серверную функцию. Интеграция работает после публикации на Netlify либо в локальной среде Netlify Dev.
- Не собирайте реальные данные клиентов до настройки понятного уведомления о конфиденциальности и проверки применимых требований.
- Перед передачей сайта клиенту замените условные услуги, цены, контакты и тексты на подтверждённые данные бизнеса.
- Добавьте защиту от спама/rate limiting перед публичным использованием. Эта заготовка ограничивает длину полей, но сама по себе не реализует полноценный антиспам.
